# Module 4: Recurrent Neural Networks for Natural Language Processing

## Word Embeddings

**Natural Language Processing (NLP)**

Fundamental concept of word vectors in NLP with neural models.

- Concept of Word Vectors

    - Each word in a vocabulary is *mapped to* a **vector**, representing a point in a multi-dimensional space.
    - Words that are similar or related are mapped to vectors that are close together, while dissimilar words are far apart.
    - The concept is likened to mapping points on a globe using **longitude** and **latitude**.
    - Just as nearby geographic points share similar characteristics, nearby word vectors indicate semantic similarity.

- Dimensionality and Learning

    - Although the analogy uses two dimensions for simplicity, actual word vectors typically have many more dimensions.
    - The mapping of words to vectors is learned from data, enabling algorithms to process words as numerical vectors for NLP tasks.

**Word to Vector (Word2Vec)**

In Word2Vec each of the vectors taht are associated with a given word is often referred to as embedding. An embedding places each word in an m-dimensional feature space, where m can vary depending on the problem (e.g., 2D, 100D, 200D).

- Mapping Words to Vectors

    - Each word in a vocabulary of *size V* is assigned an *m-dimensional vector,* creating a codebook of vectors corresponding to words.
    - The goal is for similar or related words to have vectors that are close to each other in this vector space.

- Learning Word Vectors

    - The vectors are learned from a large corpus of text through various methods.
    - Multiple learning techniques exist, often yielding similar and robust results, enabling effective natural language processing.

![Word2Vec: words mapped to vectors in an embedding space]({{ '/assets/images/ch4/word2vec-1.png' | relative_url }})

**Examples**

How word embeddings (word vectors) can be used in natural language processing (NLP) by applying Convolutional Neural Networks (CNNs) to text data.

- Word Embeddings and Text Representation

    - Each **word** in a document is mapped to an **m-dimensional vector** using a learned codebook of word **embeddings**. (based on the vocabulary codebook, that has been learned!)
     
    - A document of N words becomes a sequence of N vectors, enabling numerical analysis of natural language.
      - N number of word -(embedding)- sequence N number of m-dimensional vectors


- Applying Convolutional Neural Networks to Text

    - CNN filters of **size m** by **d** (where d is the number of words in the filter) slide over the sequence of word vectors.
    - Each filter captures patterns in d consecutive words, producing a correlation score at each position in the text.
    - 1D convolution will be performed for each K filters.
    - After the convolution N number of K-dimensional vectors are created, which will be pooled by each *row*.

- Pooling and Classification

    - Max pooling is applied to the convolution output objects to extract the highest correlation for each filter/row across the text.
    - The resulting k-dimensional vector (one value per filter) can be fed into classifiers like *logistic regression* or *multilayer perceptrons* for tasks such as *sentiment analysis*.
      - yes, this sacrifices location details for the sake of efficient classification task

- Learning Word Embeddings and Challenges

    - Word vectors can be learned jointly with CNN parameters using *labeled data*, but labeled text is *expensive* to obtain.
    - Unsupervised methods that learn word embeddings from unlabeled text are valuable to overcome the cost of labeling -- will be discussed soon.

## Representative example NLP problem: Sentiment Analysis

**Neural Models of Text**

How to learn word vectors (word embeddings) using a neural network model to *predict surrounding words in text*?

- Codebook: A set of vectors where every word in the vocabulary is mapped to a vector.

- Learning Word Vectors / Learning the Codebook

    - Word vectors map each word in a vocabulary to a numeric vector, enabling computational analysis of language.
    - The goal is to learn these vectors (the **codebook**) from a large corpus of **unlabeled** text by predicting words surrounding a given word.
      - c(w_n) = m-dimensional code for w_n.
      - m-dimensional c(w_n) = input to the MLP
      - h_n = latent hidden vector h that is d-dimensional
        - d-dimensional vector used to make predictions of surrounding words.

            $$
            h = f(W x c + b)
            $$

            - W = weight matrix
            - c = input word vector
            - b = bias vector
            - f(⋅) = activation function (e.g., ReLU, tanh, sigmoid)
            - h = hidden (latent) representation
        - The function operates pointwise or eparately in components of the vector.

- Neural Network Model for Prediction

    - Each word vector is input to a **multilayer perceptron (MLP)** that maps it to a **hidden latent vector**.
    - The hidden vector is then used to predict the probability of each word in the vocabulary appearing near the input word.

| input word vector -[MLP]-> hidden latent vector -[?]-> probability of each word to be near the input word

- Hidden Units to Words / Softmax Output and Training

    - The MLP outputs scores for all vocabulary words, converted to probabilities using the **softmax function**.
    - The model is trained to maximize the probability of actual surrounding words, *enabling learning of meaningful word embeddings*.
      - From the hidden variables the U matrix will be built for the probability outputs. The output dimansion = V-1, where V is he. size of the vocabulary.
      - $$
        u = W'^{\top}h + b
        $$

        where:

        - h∈R^N = hidden (latent) embedding
        - W'∈ R^(N×V) = output weight matrix
        - b ∈ R^V = bias vector (often omitted in Word2Vec)
        - u ∈ R^V = output logits (one score per vocabulary word)

**The Softmax Function**

- Softmax:

    $$
    \hat{y}_i
    =
    P(w_i \mid w_I)
    =
    \frac{\exp(u_i)}
    {\sum_{j=1}^{V}\exp(u_j)},
    \qquad i=1,\ldots,V
    $$

- Neural Model of Text and Softmax

    - The neural model of text uses MLP with weight matrices W and U to map input word vectors to output probabilities over a vocabulary.
    - The softmax function is applied to the output layer to convert raw scores into probabilities for each word in the vocabulary.

- Softmax as a Generalization of Logistic Function

    - Softmax *generalizes* the logistic (sigmoid) function used in binary classification *to multiple classes (words)*.
    - In the special case of a two-word vocabulary, softmax reduces to the familiar sigmoid function, showing their close relationship.

- Learning Word Vectors and Model Parameters

    - The model learns word vectors and weight parameters simultaneously by training on text corpora, using known words and their contexts.
    - This approach enables the neural model to predict the probability of words appearing near a given input word, facilitating natural language understanding.

**Methods for Learning Model Parameters**

- Word Embeddings and Document Representation

    - Each word in a vocabulary is mapped to a vector of numbers, and a document is represented as a sequence of these word vectors.
    - *Learning* good word vectors is essential for accurate text analysis and prediction.

- **Continuous Bag of Words (CBOW) Model**

    - **CBOW** predicts a target word based on the average of the **vectors of surrounding words (context)**.
    - The oder of the words does not matter as they are averaged.
    - The averaged vector is passed through a multilayer perceptron and a softmax function to estimate the probability distribution over the vocabulary for the target word.

- **Skip-Gram Model**

    - Skip-Gram works in reverse by using the vector of a given word to predict its surrounding context words.
    - This model also uses a multilayer perceptron and softmax to learn word vectors that *capture semantic relationships*.

- Model Training and Parameters

    - Both models learn word vectors (represented by matrix C) and multilayer perceptron parameters (W, U, biases) from large text corpora without requiring labeled data.
    - Successful training results in meaningful vector representations that capture the semantic meaning of words.

**More Details on How to Learn Model Parameters**

The concept of learning (*unsupervised learning*) in machine learning models, focusing on *word vector representations* and *predictive modeling* using neural networks.


- Concept of Learning in Machine Learning

    - Learning involves taking a large corpus of documents and learning the parameters of a model without human-labeled data, known as **unsupervised learning**.
    - The model parameters include word vectors and the parameters of a multi-layer perceptron (neural network) used to predict word occurrences.

- Word Vector Models: Skip-Gram and CBOW

    - Both Skip-Gram and Continuous Bag of Words (CBOW) models aim to learn word vectors by predicting a target word from its surrounding context or vice versa.
    - The input to the model is the vector representation of context words, and the output is the predicted probability distribution over possible target words using a softmax function.

- Training and Optimization

    - The training set consists of many **input-output word pairs** extracted from the corpus, with the goal to maximize the likelihood of correct predictions.
    - A **cost function** sums the log probabilities of the predicted words over all training examples, and learning **involves optimizing model parameters to maximize this function.**

## Recurrent Neural Networks and Long Short-Term Memory

**The Recurrent Neural Network**

The concept and application of **Recurrent Neural Networks (RNNs)** for natural language processing, particularly for text synthesis tasks.

- Recurrent Neural Networks Overview

    - RNNs are designed to handle sequential data by repeatedly applying the same neural network to each element in a sequence, making them suitable for **text and other time-series data**.
    - They enable tasks like *text generation, image captioning, and language translation* by predicting the next element in a sequence **based on previous context**.

![Recurrent neural network unrolled over a sequence of words]({{ '/assets/images/ch4/RNN.png' | relative_url }})

- RNN Architecture and Functioning

    - Each word in a sequence is represented as a vector (word embedding), and the RNN uses both the current word vector and a hidden state vector from the *previous step* to predict the next word --- they are concatenated (x_n-1).
    - *The hidden state captures contextual information* from prior words, allowing the model to maintain memory of the sequence as it progresses.

- Mathematical Model and Prediction Process

    - The input to the RNN at each step is the concatenation of the previous word vector and the previous hidden state vector.
    - This input is processed through a neural network with parameters (weights and biases), using a **non-linear activation function (commonly hyperbolic tangent)** to produce the current hidden state.
    - The hidden state is then used to predict the next word via a **Softmax layer**, outputting probabilities for possible next words.
    - This process repeats recurrently for each word in the sequence, enabling the generation or prediction of text one word at a time.

**Long Short-Term Memory**

- **Long Short-Term Memory (LSTM)** model, an advanced form of **recurrent neural network (RNN)** that significantly improves natural language processing tasks by incorporating **memory cells**.

- Recurrent Neural Networks and *Limitations*

    - Basic RNNs extend multilayer perceptrons by recurrently processing sequences, propagating hidden states to predict the next word.
    - *Simple RNNs struggle with long-term dependencies in text*, motivating the development of more sophisticated models like LSTM.

- LSTM Architecture and Components

    - LSTM introduces **memory cells (C)** alongside **hidden units (H)** to better capture long-term context.
    - The model uses four neural networks: *three control* networks producing vectors **i (input gate)**, **f (forget gate)**, and **o (output gate)**, and a *fourth network* generating a **candidate memory cell update (C̃**).
    - The *sigmoid function is applied to control vectors*  (restricting their values between 0 and 1), *enabling gating mechanisms.*

![LSTM cell with forget, input and output gates]({{ '/assets/images/ch4/LSTM.png' | relative_url }})

- Memory Cell Update and Output Computation\
    
    - Candidate update is cumputed using tanh function (-1 to 1).

    - The new **memory cell Cₙ** is computed by combining the **previous memory cell Cₙ₋₁** and the **candidate update C̃ₙ**, weighted by the *forget gate fₙ and input gate iₙ respectively*.
      - previous memory cell + forget gate
      - candidate update + input gate
        - 
    - The **hidden state Hₙ** is derived by applying the **output gate oₙ** to the hyperbolic tangent of the **updated memory cell Cₙ**. 
    - This gating mechanism allows LSTM to selectively retain or discard information, addressing the vanishing gradient problem in standard RNNs.

![LSTM neural network unrolled for text synthesis]({{ '/assets/images/ch4/LSTM_NN.png' | relative_url }})

**Long Short-Term Memory Review**

- LSTM Structure and Components

    - LSTM has four neural networks controlling memory: forget gate (**f**), input gate (**i**), output gate (**o**), and a *memory update network* producing a candidate memory (**c̃**).
      - **forget gate** controls h*ow much* of the previous memory *to retain*, 
      - **input gate** controls *how much new information to add*,
      - **output gate** controls *what part of the memory influences the hidden state*.

- Memory Cell and Hidden State Updates

    - The memory cell (c) is updated by combining the previous memory scaled by the forget gate and the new candidate memory scaled by the input gate.
    - The hidden state (h) is computed by applying a hyperbolic tangent to the updated memory cell and scaling it by the output gate.

- Applications and Learning

    - LSTM is state-of-the-art for natural language processing tasks like text synthesis and translation, operating on sequences of word vectors.
    - It can be trained on unlabeled data by predicting the **next word in a sequence**, and word embeddings can be learned jointly with the model parameters.

**Use of LSTM for Text Synthesis**

Explains how Long Short-Term Memory (LSTM) models are used for text synthesis and their application in tasks like **automatic image captioning**.

- Text Synthesis with LSTM

    - LSTM uses hidden units and memory cells from previous steps along with the previous word to predict the next word in a sequence.
    - The process starts with a **beginning-of-sentence (BOS)** symbol and continues predicting words until an **end-of-sentence (EOS)** symbol is generated, using a softmax layer to select the most probable next word.

- Automatic Image Captioning

    - Images are first processed by a deep convolutional neural network to **extract features** that initialize the **LSTM’s memory cell**.
    - The LSTM then synthesizes descriptive text for the image, effectively combining image analysis and text generation in an *end-to-end model*.
      - Deep CNN (Features) + LSTM (Probability -> Word synthesis) = Image-to-Caption 

- Model Training and Results

    - The combined model is trained on datasets of images paired with human-generated captions to learn parameters for both the convolutional network and the LSTM.
    - The generated captions are grammatically correct and semantically meaningful, demonstrating performance comparable to human descriptions.

## Alternative Approaches

**Simple and Effective Alternatice Methods for Neural NLP**

Explains how simple models can effectively perform natural language processing tasks like sentiment analysis, often rivaling more complex models.

- Simple Models for Sentiment Analysis

    - Sentiment analysis involves classifying text documents as *positive* or *negative* based on their content.
    - A straightforward approach averages word embedding vectors for all words in a document and feeds this average vector into a *logistic regression classifier to predict sentiment*.

- Mechanism and Effectiveness of Simple Models

    - The model implicitly assigns near-zero vectors to words that are not informative for sentiment analysis, effectively filtering out irrelevant words.
    - Alternative aggregation methods like component-wise maximization of word vectors can also be used, or both methods combined.

- Comparison with Complex Models

    - **Simple Word-Embedding Models (SWEM)** have far fewer parameters (around 61,000) compared to CNNs (540,000) and LSTMs (1.8 million), resulting in faster computation.
    - Despite their simplicity, SWEM models often achieve accuracy comparable to or better than complex models on various NLP datasets.
    - Different embedding learning methods produce different distributions of word vector values, influencing model behavior.

- Key Takeaway

    - Learning word embeddings is a powerful concept applicable across many models.
    - For many NLP tasks, simpler models like SWEM can perform very well, highlighting the importance of matching model complexity to the problem.
