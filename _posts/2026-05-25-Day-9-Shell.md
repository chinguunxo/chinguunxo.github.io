# What is Shell?

### Wildcards in Shell: `*`, `?`
They are both placeholders for characters. The Shell (bash) considers an asterisk “*” to be a wildcard character that can match one or more occurrences of any character, including no character. "?" on the other hand is used as a placeholder for only 1 character. So, multiple ?? can be used to specify the length if the file name. If you are looking for a file that has a or c you can use the [] as in `*[ac]*`.

### Shortcuts

**Home directory or "~"**

In shell, the tilde character, “~”, is a shortcut for your home directory. It is equivelant to "/home/username".

**Parent directory or ".."**

The shortcut .. always refers to the parent directory of whatever directory you are in currently.

**Current directory or "."**
`ls` and `ls .` will always be the same thing. 

**history**

Certain number of commands can be stored and displayed with `$ history`.

**Cancel a comman*

Use `ctrl + c` to cancel the current line of command and start a fresh prompt.

**Others**

`ctrl + a` will bring you to the start of the command line. 
`ctrl + e` will bring you at the end of the command line.

## Examining and creating files

### View the contents of a file

**`cat` command**

The command `cat` prints out all of the contents whitin the file. It stands for catenate. It also has many other uses.

**`less` command**

For big files, that are unsuitable to be viewed directly, `less` command opens the file in a new buffer which you can navigate through it. Shortcuts for `less`:
> [space] - forward, [b] - backwards, [g] - beginning, [G] - end, [q] - quit.
For example, for FASTQ files, the modifier `-h` can be used to see how big the files are. `$ ls -lh ~/unix_lesson/raw_fastq` will show the saie of the files in the fourth column. 
It is also possible to do searching with `less` command. Type in `/` to begin a search for strings of interest. To use it, you have to start at the beginning of the file.  

**`head` and `tail` command**

Returns the first and last 10 lines. Use `-n` to specify the number of lines. `$ head -n 2 name.fq`

### Create a new file using the Vim text editor

The two general types of text editor are:

1. GUI: graphical user interface text editors.
2. Command-line editors,

**GUI text editors**

These are like apps BBEdit, Sublime and Notepad++. As they are ‘point-and-click’, we cannot efficiently use them from the command line.

**Command-line editors**

When working remotely (connected to a cluster) it is necessary to use the command line interface. The editors Emacs, Vim, or a graphical editor such as Gedit are command-line editors for high-performance compute clusters.

**Vim interface**

By calling the text editor a new text file can be created. `$ vim draft.txt`

It will show Note the "draft.txt" [New File] typed at the bottom left-hand section of the screen. This tells you that you just created a new file in vim.

**Vim Modes**

Two modes of Vim are:

- command mode (default): will allow you to save and quit the program (and execute other more advanced commands).

- insert (or edit) mode: will allow you to write and edit text.

The modes are indicated at the left bottom corner and change between modes with [i] or [esc] keys.

**Save and Quit**

Writing is the same as saving, type `:w` when in command mode. 
After you have saved the file, the total number of lines and characters in the file will print out at the bottom left-hand section of the screen.

Alternatively, we can write to file (save changes) and quit all at once by typing :wq. Now, you should have exited vim and returned back to your command prompt.

## Searching and Redirection

### Search for character or patterns ina text file using the `grep` command.

With `grep` you can search plain-text data data sets for lines matching a pattern or regular expression (regex) can be searched. `grep` stands for globally search for a regular expression and print matching lines. (gachin nerteinbe)

It will be used as `$ grep search_term filename`, where the search_term is the pattern to be searched. 

FASTQ file structure review:
|line|description|
|1|Read ID name preceded by '@'|
|2|The actual nucleotide sequence|
|3|Read name (same as line 1) preceededd by a '+' or just a '+' sign|
|4|string of ASCII code which represent the quality score of each nucleotide in line 2 (must have the same nunmber of character as line 2)|

For all possible options of the `grep` command `grep --help` (or `man grep`)

To look for the record of all search_item 

-B and -A can be used with grep to show the lines before and after the search_item:
`$ grep -B 1 -A 2 NNNNNNNNNNN name.fq` will return the whole record.

**Group separators (--), and how to remove them**

`--` are called group separators. They interrupt the FASTQ structure. When using `grep` including `--no-group-separator` will solve this problem: `$ grep -B 1 -A 2 --no-group-separator NNNNNNN Mov10*.fq`

**Line number of the match**

`-n` will print out the line number. `$ grep -B 1 -A 2 --no-group-separator NNNNNNN Mov10*.fq`

> lines with the match will show `:` after the line number.

**If interested in the lines that do not match*

`-v` looks for an inverted match. `$ grep -v normal ~/unix_lesson/other/Mov10_rnaseq_metadata.txt`. This will show the *non*-normal lines.

### Write to and append a file using output redirection

The outputs of `grep` print to the Terminal (Standard output or "stdout").

Redirection is useful when saving the output that is once printed in the terminal into a file.

**Redirecting with ">"**

Redirection comman is simply `>`: `$ grep -B 1 -A 2 NNNNNNNNN Mov10.fq > bad_reads.txt`

The outpu will be saved in the file instead of being printed out in the terminal. The new file will also be created.

**Redirecting (and appending) with ">>"**

Redirection command for appending something to an existing file is `>>`. It only appends instead of overwriting. 

`mv` can be used tto move file: `$ mv bad_reads.txt ../other/`

### Use the pipe (`\`) character to chain together commands

**Redirecting with pipes "|" or piping**

the grep results can be viewed directly through the `head` or `less` commands using `|` 

`wc` - word count.
`$ grep NNNNNNNNN Mov10.fq | wc -l` - returns only the number of lines

The pipes are important and powerful concepts in shell and you can string along as many commands together as you like.

### GTF file format

> a new file type: Gene Transfer Format (.gtf) is a tab-delimited file with information arranged in a very specific manner, usually for NGS analysis. [More Info Here] (http://useast.ensembl.org/info/website/upload/gff.html)

| seqname | source | feature | start | end | score | strand | frame | attribute |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| chromosome or scaffold | program or data source | feature type e.g. Gene | start position (1-based) | end position (1-based) | floating point value | + or - | 0,1,2 | tag-value pairs |
| . | . | . | . | . | . | . | . | semicolon-separated |

For example, as shown in the following, any empty values should be denoted as  "." instead of being empty. 

```
X	Ensembl	Repeat	2419108	2419128	42	.	.	hid=trf; hstart=1; hend=21
```

Splice isforms are represented in the GTF file as exon being represented multiple times, once for each transcript (or splice isoform).

### More commands in Shell

**`cut` is a command that extracts columns from files**

The `cut` command with `-f` argument to specify the columns to be extracted/outputted. `$ cut -f 1,4 ch1.gtf | head` selects the 1st and 4th column.

> In case of files separated by "," or ";" etc., delimiter can be specified for 	`cut`, e.g. with `-d ","` with a .csv file.

**`sort` is a command to sort the contents of a file in a particular order**

`sort` by `-k` -- which column to sort by, and by the sorting type `n` numeric, and return only unique values `-u`.

```
cut -f 1,4 ch1.gtf | sort -1 -u | wc -l
```
